# ai-workshop

## React frontend

The standalone React frontend is in [`frontend/`](frontend/). It uses the
Campus Connect visual design in `design/stitch_campus_event_connect_hub/` and
loads event and registration data from the Flask API hosted at Render.

```bash
cd frontend
npm install
npm run dev
```

The backend base URL is configured in `frontend/local.env` as
`VITE_API_BASE_URL=https://gnu-rahp.onrender.com`. Update that value to point
the UI at a different backend. The interface has no login or authentication
flow; RSVP sends a browser generated guest ID to the existing registrations
endpoint.
